# FileSystemSimulator.

**Объяснение программы File System Simulator**

Моя программа написана на языке C++. Она предназначена для моделирования работы файловой системы компьютера.

В программе создаётся виртуальный диск размером 1 МБ. Он разделён на блоки по 1024 байта. Для хранения информации о файлах используются inode.

Программа позволяет создавать файлы и папки, записывать в них информацию, читать содержимое, удалять файлы и просматривать информацию о них.

Также реализована возможность создания жёстких ссылок, проверки фрагментации и сравнения способов размещения файлов.

Особое внимание уделено журналу транзакций. Он позволяет сохранять копию метаданных и восстанавливать их после имитации сбоя.

Для управления программой используются команды, которые пользователь вводит в консоль.

В результате программа демонстрирует основные принципы работы файловой системы и управления данными на диске.

**Вывод:** в ходе работы я изучил структуру файловой системы, принципы хранения файлов, работу с блоками и inode, а также способы проверки и восстановления данных.





1. Что такое inode?

Это структура, которая хранит информацию о файле: размер, тип, время создания и расположение данных.

2. Что такое виртуальный диск?

Это файл filesystem.img, который программа использует вместо настоящего диска.

3. Для чего нужна команда format?

Для создания и подготовки виртуального диска.

4. Для чего нужна команда fsck?

Для проверки целостности файловой системы.

5. Что такое фрагментация?

Это особенность размещения данных на диске, при которой свободное пространство или данные оказываются распределены по разным блокам.

6. Для чего нужен журнал транзакций?

Для сохранения метаданных перед операциями и восстановления их состояния после сбоя.

7. На каком языке написана программа?

На языке C++.
