# FileSystemSimulator.
1. Что такое inode?

Это структура, которая хранит информацию о файле: размер, тип, время создания и расположение данных.

2. Что такое виртуальный диск?

Это файл filesystem.img, который программа использует вместо настоящего диска.

3. Для чего нужна команда format?

Для создания и подготовки виртуального диска.

4. Для чего нужна команда fsck?

Для проверки целостности файловой системы.

5. Что такое фрагментация?

Это особенность размещения данных на диске, при которой свободное пространство или данные оказываются распределены по разным блокам.

6. Для чего нужен журнал транзакций?

Для сохранения метаданных перед операциями и восстановления их состояния после сбоя.

7. На каком языке написана программа?

На языке C++.
